سیستم صدور پیش‌فاکتور فروش — نسخه‌ی آماده‌ی انتشار (همه‌ی فایل‌ها در یک پوشه)

انتشار روی GitHub Pages (مثل SalesFlow):
1) یک مخزن (Repository) جدید در GitHub بسازید.
2) همه‌ی فایل‌های همین پوشه را (به‌جز همین README) داخل مخزن آپلود کنید (Add file ← Upload files).
3) Settings ← Pages ← Branch: main و پوشه‌ی root را انتخاب و Save کنید.
4) بعد از چند دقیقه آدرس برنامه آماده است. در Chrome گزینه‌ی «نصب برنامه» را بزنید.

نکته‌ها:
- باز کردن مستقیم index.html با دابل‌کلیک کار نمی‌کند (نیاز به http دارد)؛ از GitHub Pages استفاده کنید.
- اگر بعد از به‌روزرسانی فایل‌ها تغییر دیده نشد، یک بار صفحه را Reload کنید.
- داده‌ها فقط روی همان مرورگر ذخیره می‌شوند؛ از «تنظیمات ← پشتیبان‌گیری» نسخه‌ی JSON بگیرید.
