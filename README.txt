به‌روزرسانی — فقط همین فایل‌ها را در مخزن GitHub جایگزین کنید (هم‌نام‌ها Replace شوند).
بعد از آپلود یک بار صفحه را Reload (Ctrl+F5) کنید تا نسخه‌ی جدید فعال شود.

فونت‌های «بی‌نازنین، بی‌میترا، بی‌تیتر» فونت سیستمی‌اند: اگر روی کامپیوتر/گوشی نصب باشند خودکار کار می‌کنند.
برای استفاده روی دستگاه‌های بدون فونت، فایل‌های ttf را با این نام‌ها کنار بقیه‌ی فایل‌ها بگذارید:
BNazanin.ttf  BNazanin-Bold.ttf  BMitra.ttf  BMitra-Bold.ttf  BTitr.ttf
(بعد از افزودن فایل‌ها، برنامه را یک بار آنلاین باز کنید تا فونت‌ها برای حالت آفلاین ذخیره شوند.)
